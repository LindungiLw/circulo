# ♻️ Circulo - B2B Eco-Merch Aggregator & Impact Supply Chain

Circulo adalah platform inovatif yang menyulap limbah lokal menjadi produk *eco-merchandise* B2B premium. Kami hadir sebagai solusi satu pintu (*one-stop solution*) bagi perusahaan untuk melakukan *sourcing eco-merch* berkualitas, kustomisasi sesuai kebutuhan, pengiriman andal, serta laporan dampak ESG yang terukur.

Proyek ini dibangun sebagai purwarupa (*prototype*) interaktif untuk kompetisi *Business Model Canvas* (BMC).

## 🌟 Fitur Utama

- **Produk Eco-Merch Premium:** Merchendise berkualitas yang terbuat dari material daur ulang (sampah plastik, kain perca, dll).
- **Pemberdayaan Pengrajin Lokal:** Mendukung dan meningkatkan ekonomi para pembuat kriya dan pengrajin lokal (*Local Makers*).
- **Live Impact Dashboard:** Metrik *real-time* yang menampilkan jumlah plastik terdiversi, pengrajin yang didukung, dan pesanan korporat.
- **ESG Impact Ready:** Laporan dampak lingkungan yang transparan dan tersedia untuk setiap transaksi, siap digunakan untuk laporan keberlanjutan perusahaan.

## 🚀 Teknologi yang Digunakan

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Language:** TypeScript

## 🎨 Identitas Visual (Aesthetic)

Antarmuka (UI) dirancang dengan konsep **"Soft, Organic & Recycled"**:
- **Palet Warna:** Latar belakang *warm beige* (`#f8f7f2`), Hijau Gelap Utama (`#1a3626`), Hijau Sage Terang (`#5c8770`), dan Kuning Sekunder (`#f3c44c`).
- **Bentuk (Shapes):** Menggunakan lengkungan organik dan *border* asimetris yang menyerupai sobekan kertas daur ulang.
- **Komposisi:** Menampilkan grafik melingkar (*circular/donut chart*) berlapis yang melambangkan siklus *Circular Economy*.

## 💻 Cara Menjalankan Project

Pertama, instal semua dependensi:

```bash
npm install
```

Kemudian, jalankan *development server*:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di *browser* Anda untuk melihat *Landing Page* utama, atau kunjungi rute `/dashboard` untuk melihat purwarupa Portal Klien.
